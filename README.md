# work-web · CEEC-TERRA I

光伏项目的線上工作台：**現場施工、資料移交、TDS、尾項、會議紀要**等台賬都在同一個網站，彼此可以互相關聯。介面以英文為主、簡體中文為輔。

- 網站：靜態檔案，放在 GitHub Pages（`https://hungchenhsing.github.io/work-web/`）
- 數據：Supabase（登入、資料庫、即時同步、檔案存儲、修改記錄）
- 不載入任何外部 CDN 或 Google 字體；程式庫都放在 `vendor/` 內

`config.js` 還沒填 Supabase 時，網站以**演示模式**運行：數據只存在各自瀏覽器。

## v2 有什麼

| 功能 | 說明 |
|---|---|
| 自訂台賬 | 每個台賬有自己的欄位；可新增、刪除、改名、排序欄位，選擇類型（文字、數字、百分比、日期、選項、分類樹、勾選、網址、檔案/照片、關聯記錄、計算、子表）。 |
| 選項隨時新增 | 專業、區域、人員、分包商等是**共享列表**，也可以直接在單元格裡輸入新選項。 |
| 私有台賬 | 設為「僅自己可見」的台賬只有建立者看得到，**管理員也看不到**（由資料庫權限保證）。附件同樣私有。 |
| 修改記錄 | 每次新增、修改、刪除都由**資料庫觸發器**自動記錄：誰、何時、哪個欄位、舊值→新值。可一鍵撤銷（撤銷本身也被記錄）。 |
| 現場 + 資料 | 總覽按區域（Block B/C/D/E）匯總各台賬進度；「進度計劃」把多個台賬放在同一個甘特圖；記錄之間可以互相關聯（如施工活動 ↔ 竣工圖 ↔ 測試報告）。 |
| 視圖 | 表格（行內編輯、分組、批量修改）、看板（拖動改狀態）、甘特圖（拖動改日期）、區域矩陣（工作包 × 區域的完成量/計劃量）。 |
| 會議 | 議程、紀要、待辦事項（子表），一鍵打印會議紀要；總覽顯示未完成的待辦。 |
| 業主計劃 | 選擇台賬、記錄與欄位發布成固定快照；業主只能看到快照並逐行留言。 |
| 演示文稿（v2.2） | 用台賬數據自動生成會議簡報（封面、關鍵數據、區域矩陣、三週計劃、狀態分布、台賬表格、尾項匯總、現場照片、會議待辦、文字頁）。全螢幕演示、瀏覽器「另存為 PDF」（向量文字）；草稿時數據實時，**定稿**後凍結；可發給業主並逐頁留言。 |
| Excel | 導入時逐列對應到欄位並預覽；「提交阶段 PH-xx」自動換算成起止日期；導出當前篩選或完整備份。 |

初始模板：移交文件台賬、現場施工、尾項/缺陷清單、會議議程與紀要、TDS 技術數據表（預設私有）。

## 從 v1 升級（只做一次）

1. Supabase → **SQL Editor** → **New query** → 貼上新的 `supabase/schema.sql` 全部內容 → **Run**（可重複執行，不會刪除數據）。
2. 以管理員帳號登入網站，頁面頂部會出現 **Set up now 立即設置** → 點擊。
   - 自動建立五個台賬；原有的移交數據、分類樹、區域、專業、部門、對接人會搬到新結構。
   - 舊的 `items` 表保留不動，作為備份。

## 首次部署

1. 建立 Supabase 專案，在 SQL Editor 執行 `supabase/schema.sql`。
2. Authentication → Sign In / Providers → Email：開啟 Email provider，關閉 **Confirm email**。
3. Authentication → URL Configuration：Site URL 與 Redirect URLs 填 `https://hungchenhsing.github.io/work-web/`。
4. Project Settings → API Keys：把 Project URL 與 **Publishable key** 填入 `config.js`。**不要**放 secret / service_role key。
5. GitHub 倉庫 → Settings → Pages → Deploy from a branch → `main` / `(root)`。
6. 第一個註冊的帳號自動成為管理員；登入後點 **Set up now**。

## v2.5：速度、文件庫與雙向關聯、靈活演示

**速度**
- 首次打開：設定、台賬、記錄同時並行載入，畫面先出來；修改記錄與業主計劃之後在背景載入（先載入輕量版，需要時再取完整內容）。Excel 程式庫改為第一次導入/導出時才下載。
- 大台賬：表格與甘特圖只繪製螢幕上看得到的行（超過 150 行時啟用），看板每列先顯示 40 張卡片（「顯示更多」）。1,500 條記錄時表格約 50 ms、甘特約 35 ms、進度計劃約 40 ms（之前 360 / 200 / 515 ms）。
- 編輯器只重繪改動的區域，縮圖重用；自己的修改不會因即時同步再重繪一次。

**文件庫（左側「Documents 文件库」）**
- 每個文件是一條獨立記錄：編號（D-xxx）、標題（英/中）、文件號、版本、專業、狀態、日期、檔案、備註。可網格 / 列表瀏覽、篩選、批量修改狀態或專業、批量關聯。
- 上傳新版本：舊版本保留在「版本」列表裡。PDF 與圖片可直接預覽。
- 拖動檔案到文件庫、記錄詳情或「文件」頁即可上傳並自動建立關聯。
- 舊附件：文件庫頂部的「Move into the library 移入文件库」把各台賬記錄裡的附件一次搬進文件庫並保留關聯（可重複執行，失敗的不會刪除原附件）。

**帶類型的雙向關聯**
- 任何兩條記錄（事項 ↔ 事項、事項 ↔ 文件、文件 ↔ 文件）都能關聯，類型：相關 / 引用 / 取代 / 答覆 / 證據。兩邊都看得到，反向自動顯示（如「被取代」「被答覆」）。
- 記錄詳情的「Related 關聯」頁按類型分組，可搜尋並勾選多條一次關聯；表格編號旁的小徽章顯示關聯數量。原有的「關聯記錄」欄位也一起顯示。

**演示（Present）**
- 快捷鍵：**G** 總覽與跳頁（含隱藏的備用頁），**數字 + Enter** 直接跳頁，**Z** 放大，**L** 雷射筆，**N** 備註，**F** 聚焦篩選（只看某區域/專業/負責人，所有數據頁即時更新），**R** 臨時調出任何台賬的篩選視圖（可「加入演示文稿」），**Esc** 先關閉浮層再退出。
- 點擊數據頁上的任何一行、卡片或里程碑可下鑽看詳情（子項、關聯、照片）。業主模式只顯示業主可見的欄位與記錄。
- 業主收到的發布版只有總覽、放大、雷射筆。
- 頁面在縮圖 ⋯ 選單設為「隱藏」後即成為備用頁：正常播放跳過，總覽裡仍可打開。

## 演示文稿（Presentations）

不需要改資料庫：演示文稿存放在一個隱藏的「Presentations」台賬裡，所以權限、即時同步、修改記錄與撤銷都直接沿用。

- **新建**：左側「Presentations 演示文稿」→ New presentation → 選模板（業主週例會 / 內部進度檢查 / 空白），可直接關聯會議記錄。
- **頁面類型**：封面、關鍵數據、區域進度矩陣、近期計劃（1–8 週）、台賬表格（可選列、篩選、排序，內容多時自動分頁）、狀態分布、尾項匯總、現場照片（自動取最近 N 天或手動挑選）、會議待辦、文字要點、分節頁。
- **手動控制（v2.3）**：滑鼠移到頁面上的任何一行、一列、一條、一張照片或卡片，點 × 只在此頁隱藏（右側可恢復）；表格可「手動挑選記錄」並調整列順序；「轉為可編輯」把數據頁變成可逐格輸入的表格（可恢復實時數據）；每頁都能插入文字、便簽、方框、圓圈、箭頭、直線、圖片（可拖動、縮放，支援貼上圖片）；空白頁自由排版；撤銷/重做（Cmd+Z / Cmd+Shift+Z）；把頁面複製到其他簡報。
- **計劃視覺化（v2.3）**：里程碑時間軸（泳道、基準 ◇ vs 預測 ◆ vs 實際、延誤天數、紅黃綠狀態、今天線）、進度甘特圖（含基準條）、里程碑表（基準/預測/實際/偏差/狀態）、S 曲線（基準計劃、當前計劃、實際；實際由修改記錄與每週快照還原，可貼 Excel 補早期數據）。台賬 ⋯ 選單新增「設定基準計劃…」；記錄右上角 ◆ 可標為里程碑；新模板「關鍵里程碑」「問題、風險與決策事項」。
- **版面與匯報（v2.3）**：執行摘要頁（總體紅黃綠、計劃 vs 實際、本期完成、下一步里程碑、主要問題、需業主決策事項）；左右組合頁；配色、兩個 Logo、頁腳與密級標注，可設為默認；**導出可編輯的 PowerPoint（.pptx）**：文字、表格、形狀、圖片、S 曲線圖表在 PowerPoint 裡都能直接修改。
- **全螢幕編輯器（v2.4）**：打開文稿後隱藏網站側欄，像 PowerPoint 一樣：頂部工具列（撤銷/重做、＋頁面、插入、演示、導出、定稿與分享、⋯），左側縮圖（拖動排序、⋯ 選單：從此頁演示、複製、隱藏、複製到其他文稿、轉為可編輯、刪除），中間畫布自動放到最大，右側面板可收起，分「內容 / 版面 / 備註 / 文稿」四頁。添加頁面時有實時預覽的版型庫。
- **自由版面（v2.4）**：每頁的數據內容是一個可拖動、可縮放的區塊（版面頁也有「整頁 / 左 ⅔ / 左 ½ / 右 ½ / 上 ⅔」預設）；「插入 → 數據區塊」可在任何一頁再放入表格、關鍵數據、S 曲線、里程碑、照片等，各自設定、各自隱藏內容，定稿和發給業主時一起凍結。拖動時自動對齊頁邊、中線和其他區塊（按住 Alt 不對齊），方向鍵微調。
- **頁面設計（v2.4）**：新的「工程圖框」樣式：圖框 + 底部標題欄（項目 / 文稿 / 數據日期 / 對象或密級 / 頁碼）、結論式大標題 + 副標題、字級放大、狀態用色點；可選每頁頂部議程條（由「分節頁」生成並高亮當前一節）。文字大小可選 自動 / L / M / S，「自動」會按空間放大或縮小內容。字體 IBM Plex Sans 已打包在網站內（SIL OFL）。v2.4 之前建立的文稿保持原來的「經典色帶」樣式，可在「文稿」頁一鍵切換。
- **建議標題（v2.4）**：內容頁會根據當頁數據給出一句結論式標題（如「Turnover documents: 4 items, 2 overdue」），點「使用此標題」才會套用。
- **直接修改文字**：在預覽上點標題、副標題、文字要點即可直接改；數據頁可加「重點結論」（標題下橙色條）和「說明框」（頁面底部），數據本身仍實時更新。數字和表格請在台賬裡改。
- **數據**：草稿階段每次打開都是最新數據；點 **Issue 定稿** 後數據凍結（以後打開仍是匯報時的內容），可「Back to draft 退回草稿」或「Copy for next week 複製為下週」。
- **對象**：每份文稿可選 *Owner mode 業主模式*（只顯示「業主可見」欄位；發布給業主的台賬只顯示標記「顯示於業主計劃」的記錄）或 *Internal 內部*。「僅自己可見」的台賬**永遠不會**進入演示文稿。若業主模式下某頁的台賬沒有任何記錄標記「顯示於業主計劃」，編輯器會在頁面上方以橙色提示，並提供「改為內部」或「選擇記錄」（打開台賬 → 勾選記錄 → 「顯示於業主計劃」）。
- **語言**：每份文稿單獨選 EN / EN + 中 / 中文（預設 EN）。
- **導出 PDF**：Export PDF → 在列印對話框選「另存為 PDF」。Chrome / Edge 會自動使用 16:9 頁面；Safari 請選橫向。
- **發給業主**：Share with Owner 會先定稿，再把凍結的數據（照片壓縮後內嵌）發布到「業主計劃」；業主可演示、下載 PDF、逐頁留言，意見回到該文稿的編輯頁。
- **與其他功能聯動**：台賬 ⋯ 選單「把當前視圖加入演示文稿」（沿用當前篩選與列）、記錄的「文件」頁「把照片加入演示文稿」、會議記錄頂部可直接打開或新建該會議的演示文稿。

## 角色

| 角色 | 能做什麼 |
|---|---|
| Admin 管理員 | 全部團隊台賬，審批用戶，刪除團隊台賬 |
| Editor 編輯 | 查看與修改團隊台賬，建立台賬 |
| Viewer 只讀 | 查看團隊台賬；可建立自己的私有台賬 |
| Owner 業主 | 只能看發布的快照並留言 |
| Pending 待審批 | 什麼都看不到 |

私有台賬只屬於建立者，與角色無關。

## 注意事項
- **中國大陸訪問**：`github.io` 和 `supabase.co` 在大陸不保證穩定。網站本身不依賴外部 CDN；若長期打不開，可把這個資料夾放到國內靜態托管（需備案網域）。
- **Supabase 免費版**：連續 7 天沒有任何訪問會暫停，到控制台恢復即可（數據不會丟）。
- **備份**：Settings › Data & backup 下載 Excel（每個台賬一張表）或 JSON。
- **檔案與照片**：存在私有存儲桶 `files`（路徑 `r/<台賬>/<記錄>/…`），跟隨台賬的可見範圍；單檔 ≤ 50 MB。
